# Fine-tuning SAM for Mitochondria Segmentation

This repository contains the code for fine-tuning the Segment Anything Model (SAM) on electron microscopy images of the CA1 hippocampus region for the segmentation of mitochondria.

## Overview

The work is organized in two Jupyter notebooks:

- `fine_tuning_sam.ipynb` — data preparation, patch extraction, dataset construction, model loading and fine-tuning of the SAM mask decoder.
- `prediction.ipynb` — loading the fine-tuned model, plotting the training curves, and running inference on validation patches with bounding box prompts.

## Model: Segment Anything Model

SAM is a promptable segmentation model developed by Meta AI. Unlike classical object detectors, SAM does not predict regions of interest on its own: it receives an image along with a prompt (a point, a bounding box, or a coarse mask) and returns the segmentation mask of the object indicated by that prompt. The architecture is composed of three blocks: a vision encoder (a Vision Transformer that transforms the image into a dense representation), a prompt encoder (which transforms the user prompt into a vector representation), and a mask decoder (which combines both representations to produce the final mask).

SAM was pre-trained on more than one billion masks from eleven million natural images, giving it strong generalization capabilities. However, electron microscopy images differ substantially from natural images: they are grayscale, contain very fine textures, and display specific biological structures. A fine-tuning step is therefore necessary to adapt the model to this domain.

In this project, the model used is SAM ViT-B, the smallest variant of the SAM family, well suited to the computational resources available. Only the mask decoder is trained; the vision encoder and the prompt encoder are frozen. This strategy is standard for fine-tuning on modest datasets and drastically reduces memory consumption while preserving the general visual representations learned during pre-training.

## Data

The data comes from the public dataset of the EPFL laboratory, dedicated to the analysis of electron microscopy images of brain tissue. It was acquired from a section of the CA1 hippocampus region, with a voxel resolution of approximately 5×5×5 nanometers.

The complete volume covers 1065×2048×1536 voxels. The training sub-volume used in this work contains the first 165 slices of the stack, on which mitochondria have been manually annotated. The data is provided as two TIFF stacks: one with the raw images (165×768×1024) and one with the corresponding binary masks.

The data is publicly available at https://www.epfl.ch/labs/cvlab/data/data-em/ and is not included in this repository.

## Approach

Each slice of the 768×1024 stack is divided into patches of 256×256 pixels, without overlap. Patches containing no annotated mitochondria are discarded, since they provide no learning signal and can produce unstable gradients. The remaining patches are split into a training set and a validation set (80%/20%), using a fixed random seed for reproducibility.

During training, the input to SAM is a patch of 256×256 pixels and the bounding box computed from the ground truth mask. A random perturbation is added to the box coordinates so that the model learns to remain robust to imperfect localizations at inference time. The loss combines Dice and cross-entropy (DiceCELoss from MONAI).

The training is tracked with the Dice coefficient on the validation set. The best model is saved based on validation Dice, and early stopping is applied with a patience of seven epochs.

## Results

The model converges smoothly and generalizes well. Training stops at 30 epochs with a best validation Dice of 0.9391, obtained at epoch 28. The gap between training and validation Dice remains below one point throughout, indicating that the fine-tuning is well regularized and that the frozen encoders effectively prevent overfitting on the small dataset.

On individual validation patches, the model produces clean masks that closely match the reference. The inference notebook includes a comparison of several thresholds on the probability map, showing that a threshold of 0.45 slightly improves the filling of mitochondria compared to the usual 0.50.

## Requirements

Python 3.10 or higher is required. The dependencies are listed in `requirements.txt`. They can be installed with:

pip install -r requirements.txt

The inference steps run on CPU. Training was performed on a GPU, but no GPU-specific code is required in the notebooks.

## Repository structure

The repository contains the two main notebooks, the dependency file, and this README. The data and the trained model weights are not included. They can be regenerated by running `01_training.ipynb` after downloading the data from the EPFL website.
